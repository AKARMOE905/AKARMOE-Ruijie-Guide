Optimize ခလုတ်က ဘာလုပ်သလဲ?
Ruijie က Channel သို့မဟုတ် Wireless optimization ကို အကြံပြု/လုပ်ဆောင်နိုင်တဲ့ ခလုတ်ဖြစ်ပါတယ်။ App က ပြသတဲ့ confirm စာကိုဖတ်ပြီးမှ အတည်ပြုပါ။ Optimize အလုပ်လုပ်ပုံက Device/Firmware အလိုက် ကွာနိုင်ပါတယ်။
Manually → No interference ပဲပြနေတယ်
Manual Channel စာမျက်နှာမှာ ရွေးစရာ Channel မပေါ်ဘဲ “No interference” ပြနေခဲ့တာ သင်ပို့တဲ့ Screenshot အရ တွေ့ရပါတယ်။ ဒီစာမျက်နှာကနေ Channel ပြောင်းပြီးပြီလို့ မဆိုနိုင်ပါ။ Back ပြန်ပြီး AP ရဲ့ Radio/Wireless setting ကို စစ်ဆေးပါ။

Wi-Fi Config ကို နားလည်ရန်

သင်ပို့ထားတဲ့ Wi-Fi Config Screenshot အရ အောက်ပါ setting များကို မြင်ရပါတယ်။

Security / Encryption Type
Wi-Fi လုံခြုံရေးနဲ့ password encryption ပုံစံကို သတ်မှတ်ရာနေရာ။ သင့်ပုံမှာ Security: Do Not Encrypt၊ Encryption Type: OPEN လို့ပြထားပါတယ်။ Wi-Fi ကို password မလိုဘဲ ဖွင့်ထားတဲ့အခြေအနေဖြစ်နိုင်တာကြောင့် အများသုံး network မဟုတ်ရင် လုံခြုံရေးကို သေချာစစ်ပါ။
SSID Hiding
Wi-Fi နာမည်ကို ဖုန်း Wi-Fi list မှာ မဖော်ပြစေဖို့ ဖျောက်ထားခြင်း။ ဖျောက်ထားရင် အသုံးပြုသူက SSID ကို ကိုယ်တိုင်ရိုက်ထည့်ရနိုင်ပါတယ်။
Apply to • All devices
Setting ကို သက်ဆိုင်ရာ device အားလုံးသို့ သက်ရောက်စေမလား ရွေးချယ်ရာနေရာ။ ပြောင်းမယ်ဆိုရင် ဘယ် AP/SSID တွေသက်ရောက်မလဲ စစ်ပါ။
Wi-Fi Schedule • ALL Time
Wi-Fi ဖွင့်/ပိတ်ချိန်ဇယား။ ALL Time ဆိုတာ ပုံထဲမှာ အချိန်ကန့်သတ်မထားတဲ့ရွေးချယ်မှုလို့ ပြထားပါတယ်။
Wireless mode • Auto
Wi-Fi အလုပ်လုပ်မယ့် mode ကို သတ်မှတ်ခြင်း။ App မှာ Auto ဖြစ်နေပါတယ်။ စက်ဟောင်းတွေ SSID မတွေ့/မချိတ်နိုင်ရင် compatibility mode ကို စဉ်းစားနိုင်တယ်လို့ App က မှတ်ချက်ပေးထားပါတယ်။
VLAN ID • 1
SSID ကို network VLAN တစ်ခုနဲ့ ချိတ်ဆက်သတ်မှတ်တဲ့ နံပါတ်။ သင့်ပုံမှာ 1 ဖြစ်ပါတယ်။ Network စီမံသူက သတ်မှတ်ထားတဲ့ VLAN မသိဘဲ မပြောင်းပါနဲ့။
Client Isolation / Layer 2 Isolation
Wi-Fi client စက်တွေ အချင်းချင်း network access မလုပ်နိုင်အောင် ကန့်သတ်တဲ့ setting များ။ Printer, local file share, casting စတာတွေ သုံးနေရင် ပိတ်ဆို့နိုင်တာကြောင့် လိုအပ်ချက်သိမှ ဖွင့်ပါ။
SSID Encoding • UTF-8
Wi-Fi နာမည်စာသား encoding။ App မှာ UTF-8 ကို ရွေးထားပြီး ပုံမှန်အသုံးပြုမှုအတွက် သင့်တော်တဲ့ default ဖြစ်ပါတယ်။

လုံခြုံစွာ Setting ချတဲ့အဆင့်များ

1 AP ကို ရွေးပါ
Ruijie App → Devices → သင့် AP နာမည် (ဥပမာ Naw pale) ကိုဖွင့်ပါ။ စက်နာမည်နဲ့ serial ကို မှန်မမှန် စစ်ပါ။
2 Setting မပြောင်းခင် လက်ရှိအခြေအနေ မှတ်ထားပါ
SSID, Security, VLAN, Channel နဲ့ လက်ရှိတန်ဖိုးတွေကို Screenshot သိမ်းထားပါ။
3 Wi-Fi နာမည် / Password ပြောင်းရန်
Wi-Fi Config ထဲက SSID သို့မဟုတ် Security/Encryption option ကိုရှာပါ။ Password ထည့်ရမယ့် field မမြင်ရရင် အတင်းမပြောင်းပါနဲ့။ လုံခြုံတဲ့ WPA2/WPA3 option ကို စက်က ပံ့ပိုးသလို ရွေးပါ။
4 Channel ပြဿနာ စစ်ရန်
Diagnose → Channel Usage ကိုဖတ်ပါ။ Optimize ရှိရင် အကြံပြုချက်ကို အတည်ပြုပါ။ Manual page မှာ Channel ရွေးစရာ မပေါ်ပါက Devices/AP → Wireless/Radio setting မှာ ရှာပါ။ Menu ပုံစံက firmware အလိုက် ကွာနိုင်ပါတယ်။
5 Save / ပြန်စစ်
ပြောင်းထားတဲ့ setting ကိုသာ Save လုပ်ပါ။ Wi-Fi ခဏပြတ်နိုင်ပါတယ်။ ပြန်ချိတ်ပြီး Diagnose again နဲ့ စစ်ပါ။ Factory Reset ကို မလိုအပ်ဘဲ မနှိပ်ပါနဲ့။
ဒီ HTML လမ်းညွှန်က Ruijie App ကိုယ်တိုင် မဟုတ်ပါ။ Router/AP ကို တိုက်ရိုက်မထိန်းချုပ်ပါ။ App ထဲမှာ ကိုယ်တိုင် Setting လုပ်ရာမှာ မြန်မာလို ရှင်းပြပေးတဲ့ offline guide ဖြစ်ပါတယ်။

RG-RAP6262 • စက်ချိတ်ဆက်လမ်းညွှန်

သင့် outdoor access point ကို Ethernet/PoE သို့မဟုတ် DC power နဲ့ချိတ်ပြီး Ruijie Cloud မှာ စီမံဖို့ အခြေခံအဆင့်များ။

မော်ဒယ်ခွဲ (RAP6262 / RAP6262(G)) နဲ့ hardware revision အလိုက် port ပုံစံအနည်းငယ်ကွာနိုင်ပါတယ်။ စက်ပေါ် label နဲ့ official manual ကိုစစ်ပါ။ Factory Reset မလုပ်ခင် လက်ရှိ config/password ကို သိမ်းထားပါ။

① စက်နဲ့ Port များ

LAN/PoE • Ethernet

Network cable ကို AP ရဲ့ LAN/PoE port သို့ ချိတ်ပါ။ အခြားဖက်ကို 802.3at PoE+ ပံ့ပိုးတဲ့ switch/injector port သို့ ချိတ်နိုင်ပါတယ်။

DC 12V input

PoE မသုံးဘဲ power adapter သုံးမယ်ဆိုရင် model manual က သတ်မှတ်ထားတဲ့ 12V DC / 2A adapter ကိုသာ သုံးပါ။

RESET hole

Official installation guide အရ အချို့ RAP6262 variant တွင် short press က reboot ဖြစ်နိုင်ပြီး 5 စက္ကန့်ကျော်ဖိထားရင် factory reset ဖြစ်နိုင်ပါတယ်။ Reset behavior ကို မိမိ model guide နဲ့အတည်ပြုပါ။

② ချိတ်ဆက်ပုံ (ရိုးရှင်းသော Network)

Internet / ISP

⬇ Ethernet / WAN

Router သို့မဟုတ် PoE+ Switch / Injector

⬇ LAN cable (PoE+ ဖြစ်ပါက data + power တစ်ကြိုးတည်း)

RG-RAP6262 Access Point

⬇ Wi-Fi

ဖုန်း / Laptop / Wi-Fi Client

PoE switch သုံးပါက RAP6262 ကို 802.3at PoE+ ပံ့ပိုးသည့် port သို့ ချိတ်ပါ။ PoE injector သုံးပါက Data/LAN နဲ့ PoE output port ကို injector label အတိုင်း ချိတ်ပါ။

③ ပထမဆုံး Cloud Setup

1 Power နဲ့ Ethernet ချိတ်ပါ
PoE+ switch/injector ကို ဖွင့်ပြီး AP ကို power ပေးပါ။ Waterproof outdoor installation မလုပ်ခင် cable gland/seal များကို manual အတိုင်း တပ်ပါ။
2 LED အခြေအနေကြည့်ပါ
System LED လင်း/flash ပုံစံက startup, Internet မရခြင်း၊ normal operation စတာတွေကို ညွှန်ပြနိုင်ပါတယ်။ LED meaning က hardware version အလိုက် manual ကိုကိုးကားပါ။
3 Ruijie Cloud / Reyee App မှ Device ရှာပါ
App ထဲ Network သို့မဟုတ် Devices ကိုဖွင့်ပြီး Discover/Add device လုပ်ပါ။ Device မတွေ့ရင် power, Ethernet link, DHCP/router Internet access နဲ့ Cloud account/network ကိုစစ်ပါ။ Cloud onboarding menu က App/firmware version အလိုက် အမည်ကွာနိုင်ပါတယ်။
4 Network setup လုပ်ပါ
Network name သတ်မှတ်ပါ။ Internet uplink ကို ISP အတိုင်း DHCP သို့မဟုတ် PPPoE ရွေးပါ။ PPPoE ဖြစ်ရင် ISP ပေးထားတဲ့ username/password ကိုသာ ထည့်ပါ။ Wi-Fi SSID နဲ့ လုံခြုံတဲ့ password သတ်မှတ်ပါ။ Device management password ကို သီးခြားခိုင်မာစွာထားပါ။
5 Online စစ်ဆေးပါ
Devices list မှ RAP6262 Online ဖြစ်/မဖြစ်၊ IP address ရ/မရ၊ client Wi-Fi ချိတ်နိုင်/မနိုင် စစ်ပါ။ ပြီးရင် Diagnose နဲ့ Channel Usage စစ်ဆေးပါ။

④ Troubleshooting

AP မီးမလင်း
PoE source က 802.3at PoE+ ပံ့ပိုးမှုရှိ/မရှိ၊ injector power, DC adapter specification နဲ့ cable link ကိုစစ်ပါ။
Cloud မှာ AP မတွေ့
LAN cable, router DHCP, Internet connection, AP startup time နဲ့ app/network မှန်မမှန်စစ်ပါ။ Factory reset ကို နောက်ဆုံးနည်းလမ်းအဖြစ်သာ သုံးပါ။
Wi-Fi နှေး / Channel issue
App Diagnose → Channel Usage ကိုစစ်ပါ။ သင့် Screenshot မှာ 2.4GHz Channel 6 = Block၊ 5GHz Channel 36 = Good လို့ပြထားပါတယ်။ Optimize စမ်းပြီး မရပါက AP Devices → Wireless/Radio settings ထဲက channel ရွေးစရာကို ရှာပါ။
